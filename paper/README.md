# Manuscript source

`sn-article.tex` is the manuscript as submitted in the second revision round
(clean version, without revision mark-up). It compiles in this directory with
pdfLaTeX + BibTeX; the class file, bibliography style, `.bib` file and the eight
figure PDFs are all present.

```bash
pdflatex sn-article && bibtex sn-article && pdflatex sn-article && pdflatex sn-article
```

The figures are the same files as in `../results/revision2/figures/` and are
regenerated by the scripts in `../scripts/revision2/`.
